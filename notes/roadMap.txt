## Expanded Checklist (Reflecting Current Progress & Goals)

1. **Data Pipeline**
    - ✔️ Gathered and cleaned historical football match data.
    - ✔️ Engineered features (odds, recent form, team stats, contextual variables).
    - **Ready for production use.**

2. **Model Building**
    - ✔️ Trained and compared baseline models (RandomForest, XGBoost).
    - ✔️ Tuned RF for HomeWin; XGBoost optional for marginal gains.
    - ✔️ Analyzed feature importances.
    - **Final focus:** HomeWin prediction, pushing accuracy toward 70%.

3. **Evaluation**
    - ✔️ Assessed model with metrics (accuracy, F1, recall, threshold tuning).
    - ✔️ Optimized threshold for business goals (betting/decision support).
    - ✔️ Validated on unseen evaluation set.
    - **Business simulation:** Betting strategy and value analysis complete.

4. **Deployment (API)**
    - 🔜 Package final HomeWin model as REST API (Flask/FastAPI preferred).
    - 🔜 Provide notebook/script demo for local testing and stakeholder review.
    - **Priority:** Reliable, easy-to-use interface for predictions.

5. **Cloud Hosting**
    - 🔜 Deploy API to AWS, Heroku, or Render.
    - 🔜 Document steps and ensure reliability (uptime, basic monitoring).
    - **Goal:** Accessible for demo and/or real usage.

6. **Integration (Optional Bonus)**
    - ⬜️ Connect API to WhatsApp bot or simple web UI, if time allows.
    - ⬜️ Not required for sprint completion, but adds engagement value.

7. **Docs & Demo**
    - 🔜 Write/update README with setup, usage, and findings.
    - 🔜 Finalize technical report: methodology, results, business impact.
    - 🔜 Add screenshots, tables, or a short demo video for presentation.
    - **Goal:** Clear communication for stakeholders and users.
