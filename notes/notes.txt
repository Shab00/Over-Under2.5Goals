# Project Notes — 2025-08-22

Pivoting from Categorical to Linear (Regression) Prediction

Originally, our model focused on categorical prediction, such as predicting the outcome of a football match as Win/Draw/Loss or Over/Under goals (i.e., classification tasks). In this approach, the model outputs a discrete label, and evaluation metrics include accuracy, F1-score, etc.

We are now pivoting to linear (regression) prediction, where the model predicts the actual number of goals scored by each team in a match (continuous values). This enables us to:

    Directly estimate expected goal counts (e.g., 1.3 goals for Home, 0.9 for Away).
    Use these predictions to derive probabilities for different outcomes (like over/under lines, correct scores) via Poisson models.
    Evaluate performance using regression metrics such as Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).

In summary:
We’re moving from predicting categorical outcomes to predicting continuous goal counts, making our model more flexible and valuable for deeper football analytics and probability-based predictions.

- Create ratios and spreads, e.g. over/under odds ratio, home/away odds ratio.

- Add all selected odds columns and engineered features to your feature list.

_Interpretation:_  
Lowering the threshold to 0.25 makes the model much more aggressive in predicting positives:

- Precision drops to 0.47 (more false positives)
- Accuracy drops, since more predictions are "home 2+", increasing the chance to be wrong if negatives dominate.

# Calibration Workflow: Home 2+ Goals Model

## Objectives
- Assess if the predicted probabilities from the tuned RandomForest model for `target_home_plus_two` are well-calibrated.
- If calibration is poor, apply probability calibration (e.g., isotonic, Platt scaling) to improve reliability.

---

## Steps

### 1. Plot Calibration Curve
- Use `calibration_curve` from `sklearn.calibration`.
- Compare predicted probabilities vs. fraction of positives.
- Plot "perfect calibration" line for reference.

### 2. Quantitative Assessment
- Optionally compute Brier score (`sklearn.metrics.brier_score_loss`).
- Look for deviations in the calibration plot: overconfidence, underconfidence, etc.

### 3. Calibration Methods
- If calibration is poor, fit a `CalibratedClassifierCV` (method: `'isotonic'` or `'sigmoid'`).
- Retrain calibrated model on training data.
- Plot calibration curve for calibrated model.

### 4. Evaluation
- Compare pre- and post-calibration curves.
- Recompute classification metrics (F1, precision, recall) at optimal threshold.
- Note any changes in threshold or performance.

### 5. Save/Export
- Save calibration plots and key metrics for reporting.
