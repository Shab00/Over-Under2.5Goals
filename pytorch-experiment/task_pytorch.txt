WHAT TO BUILD:

1. src/dataset.py
   - FootballDataset(torch.utils.data.Dataset)
   - Loads ../data/processed/engineered_train_features.csv
   - Target: FTR == 'H' (home win) → 1, else 0
   - Uses the SAME 218 feature list as the LightGBM model
     (load from ../models/weekly/homewin/feature_list_*.pkl, take the latest)
   - Handle NaN in features (LightGBM handles them natively; PyTorch doesn't —
     fill with column means OR use torch.nan_to_num; pick whichever keeps
     training stable)
   - TIME-BASED split: sort by Date, use first 70% for train, next 15% for
     val, last 15% for test. No random shuffling across time.

2. src/model.py
   - HomeWinNet(nn.Module): 3-layer MLP
     * input → Linear(218, 128) → BatchNorm1d(128) → ReLU → Dropout(0.3)
     * 128 → Linear(128, 64) → BatchNorm1d(64) → ReLU → Dropout(0.3)
     * 64 → Linear(64, 1) → Sigmoid (return logits before sigmoid; use
       BCEWithLogitsLoss for numerical stability)
   - Forward method returns raw logits

3. src/train.py
   - Loads dataset, creates DataLoaders (batch_size=64)
   - Trains HomeWinNet for up to 100 epochs
   - Loss: BCEWithLogitsLoss
   - Optimiser: Adam, lr=1e-3
   - Scheduler: ReduceLROnPlateau(patience=5, factor=0.5)
   - Early stopping: patience=10 on val loss, restore best weights
   - Logs to MLflow:
     * Hyperparameters (lr, batch_size, dropout, layers, epochs_trained)
     * Per-epoch train_loss and val_loss as metrics (with step)
     * Final test metrics: Brier score, log-loss, ROC-AUC, accuracy
     * Saves model with mlflow.pytorch.log_model
   - Saves a training curve plot (loss vs epoch) to ../pytorch-experiment/artifacts/loss_curve.png

4. src/train_lgbm_baseline.py
   - Trains a fresh LightGBM on the SAME train split and SAME 218 features
     (do NOT load the production model; train a clean baseline on the same
     split so the comparison is apples-to-apples)
   - Uses default LightGBM hyperparameters close to what
     ../jobs/train_model.py uses (read that file to match)
   - Logs to MLflow under the same experiment, run name "lightgbm_baseline"
   - Logs the same metrics: Brier, log-loss, ROC-AUC, accuracy

5. src/compare.py
   - Loads both runs from local MLflow
   - Evaluates both on the SAME held-out test set (last 15% by date)
   - Produces:
     * Comparison table printed to stdout: model | Brier | LogLoss | AUC | Accuracy
     * Calibration comparison plot (reliability diagram) saved to
       ../pytorch-experiment/artifacts/calibration_comparison.png
     * Saves the table as ../pytorch-experiment/artifacts/comparison.csv
